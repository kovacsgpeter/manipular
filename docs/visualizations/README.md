## Szerkeszthető fragmentumok

- [Játékfelület-wireframe forrása](fragments/cynoscephalae-game-wireframe.fragment.html)
- [Koncepcióinterjú forrása](fragments/cynoscephalae-interju.fragment.html)

A fragmentumok az inline vizualizáció szerkeszthető változatai. A standalone HTML-fájlok ezekből készültek a Visualize renderelőjével. A repóbeli interjú nem függ a Codex host API-jától: az elkészült válaszösszegzést kijelöli és lehetőség szerint a vágólapra másolja.

A Codex saját vizualizációs könyvtárában lévő példányok megmaradhatnak, de ez a mappa a két felület teljes, repóban tárolt másolatát tartalmazza.
