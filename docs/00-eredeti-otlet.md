# Eredeti ötlet

> A következő szöveg a kezdeti brief változtatás nélküli másolata.

először ötletlejünk, szeretnék egy olyan gamifikácios minialklamzást / játékot, aminek aza célja, hogy gamifikált modon rávegye a userket, vállalt célok teljesitesere, pl sport, szövegtanulás, fb poszt, kapcsolat épites stb.  - a jatek gamifikacios tematikaja az a Battle of Cynoscephalae csata és közbetlen előzménye. A fő képernyő egy térkép lenne Thessaly - ábárzolva ilyen régebbi arcad game stilusban, amin kirajzoldonanakk a sematikus topográfiai elemek, varosok, és a gamifikacios roadmap, allomasokkal. Lenne egy almenu: a tábor, amiben sematikus romai tábor elemek lennenek abrazolva. Mind a fő térkép képernyon mind a tábor képernyőn egyes elemek on cursor kivilagosodnanak és ott kölcsönhatasba lehetne lepni, pl feladat teljesites, statusz/pontok lekérdezése stb. . A küldetes az küslő fileből töltődne be emiatt a képernyő meg játékmotor alapvetően csak keret, a story az cserélhető lenne. Hetente lenne új story file amivel a fő tékrépne lehet elrőe haladni a feladatok kihivasok teljesitese altal. A jatek vege a nagy csaata, amiben sereged allapota attol függ hogy mennyire tudtal gyujteni előtte. A jatekot 3 coop játszanék, szoval az együttes teljesitmeny is szamitana a gyüjtési szakaszban. Lennenek merfőldkő csaták vagy iylesmi. Az ellenfél az elepvetően a gép/játék. Egyes fealadtok teljesíteset ugy lehetne csak verifikjálni hogy egy magadott email cimről kell küldeni emialt vagy ilyesmi. Az első verzio egy lapvetően github repoban syncelt dolgo lenne. Minden jetékos (3 coop) kicsekkolja a repot és elinditja az laklamazástlokál, ami egy bongészos valami lenne, alapvetően javascript, html css valami jobb keretrsndszerben. A perzisztencia egyelőre file lenne, egyénileg midnenkinek lenne egy. Save re az alkalmazás commitol és pushol. A verifikacios dologra kéne egy megoldás hogy lehetne automatizalni. Segits ötletleni, megtrevezni - ezt a szöveget metsd el egykülön fileba repoba, és egy másikat is amiben a te átiratod van, kicsit értelmesebben rendszerezetteben megfoglamazva, és 3. ba meg egy tervet. Kérdezz, interjuztass addig amig az ötlet elkezhető lesz.
